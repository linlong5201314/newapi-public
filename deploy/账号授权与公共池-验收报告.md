## 2. 关键实现点

- 平台渠道（`owner_id=0`）**必须 `visibility=1` 才会被普通用户路由到**；用户自建渠道始终可用，他人渠道只有公开才可见。
  - SQL 路径：`model/ability.go` 子查询 `(owner_id IN ? AND owner_id <> 0) OR visibility = 1`
  - 内存缓存路径：`model/channel_cache.go` 的 `pickPlatformPublic()` / `pickPublic()`
- 传播延时：可见性变更对**其它节点**最多 `SYNC_FREQUENCY`（默认 60s）后生效；变更所在节点立即生效。
- 账号加密：`enc:v1:<base64url(nonce+sealed)>`，key = `sha256("new-api:crypto:v1:" + CRYPTO_SECRET)`（AES-GCM）。
- 面板凭据互通：`X-Internal-Secret: <CRYPTO_SECRET>` 才能访问 `/api/internal/*`。

## 4. 已知边界

1. **自动开通目前只支持 DS2API**（DeepSeek 网页版账号）。Qoder / MiniMax / Gemini 2api / Trae 需要先各自部署配套网关，绑定会被标记为 `failed` 并给出中文原因，不会卡在「开通中」。
2. Cline / OpenCode 属「自带 key」类型（`authMode=key`，base 可见），用户填自己的 key 即可用，不需要账号密码。
3. Turnstile 不做脚本自动勾选（反机器人校验），需要人工点一次。
