与后端契约的对齐（对照同期落地的 M2-BE 代码核实）
============================================================================
- /api/route_rule 六端点与 router/routerule-router.go 完全一致：
  GET / · GET /:id · POST / · PUT / · DELETE /:id · POST /:id/toggle。
- 写入负载 targets/config 发送结构化 JSON（非字符串），匹配
  controller/route_rule.go routeRuleRequest{Targets []model.RouteRuleTarget,
  Config *model.RouteRuleConfig}；target 元素字段
  channelId/weight/fallbackOnlyOnQuotaExhaustion 与 model 层 json tag 一致。
- 列表响应识别 data.{items,total,max_per_user,strategies} 信封；
  max_per_user 透出为创建按钮禁用 + "n/max 条规则" 计数。
- 策略 8 项与 service/strategy.Names() 逐字一致：
  priority/weighted/round-robin/random/least-used/lowest-latency/lkgp/reset-aware。
- 表单默认值对齐 model/route_rule.go：maxRetries=1、retryDelayMs=1000、
  targetTimeoutMs=30000。
- free_templates 响应识别 data.items；模板字段
  id/name/channelType/baseUrl/models/freeNote/monthlyTokens/freeType/
  extraFields/poolKey/tos/signupUrl/keyRequired 与
  constant/free_sources.go FreeSourceTemplate 一致。
- from_template 提交 {templateId, key, name?, extra?}；
  extraFields（如 cloudflare-ai accountId）渲染必填输入并放入 extra。
- free_usage 识别 {templateId,name,monthlyTokens,usedThisMonth,remaining,
  resetsAt}；remaining=null（uncapped）时按 monthly-used 兜底，
  resetsAt=null 显示「重置时间未知」。
- fail-soft：读路径（free_templates/free_usage/规则列表信封解析/渠道选项）
  全部容忍 404/403/字段漂移，退化为空态而非报错；写路径错误经
  handleServerError 统一 toast。
